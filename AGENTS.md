# Verificação de correções

- Para cada bug corrigido, crie ou estenda um teste automatizado de regressão que reproduza a falha e confira o comportamento correto.
- Execute os testes relacionados e a suíte `npm.cmd test` antes de concluir. Diferencie testes simulados de verificações reais; não consuma créditos de geração nos testes automatizados.
